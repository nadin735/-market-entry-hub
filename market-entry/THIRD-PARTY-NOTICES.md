# Drittanbieter Komponenten

Stand der Angaben: nach Herstellerangaben (Paketbeschreibungen), NICHT automatisch geprüft.
Vor einer Veröffentlichung bitte mit `npm install && npx license-checker --summary` abgleichen
und die Ausgabe hier einfügen.

| Paket | Zweck | Lizenz (laut Hersteller) |
|---|---|---|
| react, react-dom | UI | MIT |
| recharts | Diagramme | MIT |
| lucide-react | Icons | ISC |
| @fontsource/inter | Schrift Inter | OFL 1.1 (Schriftdateien) |
| @fontsource/noto-sans-arabic | Schrift Noto Sans Arabic | OFL 1.1 (Schriftdateien) |
| vite, @vitejs/plugin-react | Build | MIT |
| tailwindcss, postcss, autoprefixer | Styling | MIT |

Eigene Bestandteile ohne Fremdlizenz: PDF Textextraktion (eigene Implementierung, keine Bibliothek).

## Inhalte und Daten
- Wirtschaftsdaten stammen aus den in der App genannten Quellen (z. B. Weltbank). Die Quellen werden je Angabe genannt. Prüfe die Nutzungsbedingungen der jeweiligen Quelle, bevor du Daten kommerziell weitergibst.
- Logos und Bilder in `public/`: Nutzungsrechte bitte selbst bestätigen.
