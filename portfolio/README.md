# Portfolio – Nadin Okil

Eine einzige, in sich geschlossene Datei: `index.html` (alle Bilder eingebettet, DE/EN/AR, kein Build nötig).

Deployment: den Ordner `portfolio/` auf Vercel/Netlify/GitHub Pages oder einen beliebigen Webserver hochladen.
Zum lokalen Ansehen genügt ein Doppelklick auf `index.html`.

## Vor dem Veröffentlichen
1. `npm install && npm run fonts` (lädt die Schriften lokal in `fonts/`; keine Verbindung zu Google Fonts).
2. In `impressum.html` und `datenschutz.html` alle `[PLATZHALTER]` ausfüllen; rechtlich prüfen lassen (Entwurf, keine Rechtsberatung).
3. Impressum nennt bewusst keine Straße (Anschrift auf Anfrage). Bei Bedarf c/o-Adresse eintragen.
